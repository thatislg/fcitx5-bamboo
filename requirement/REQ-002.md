# REQ-002: Hướng Dẫn Build và Cài Đặt fcitx5-bamboo-mint

**Phiên bản:** 1.0  
**Ngày cập nhật:** 2026-08-16  
**Ngôn ngữ:** Tiếng Việt  
**Mục đích:** Hướng dẫn chi tiết quy trình build và cài đặt addon `bamboomint` sau mỗi lần chỉnh sửa code.

---

## 1. Tổng Quan Quy Trình

Dự án này có 2 phần chính cần build:

1. **Phần Go** (`bamboo/bamboo-core/`) — Thư viện lõi xử lý tiếng Việt, build ra file `bamboo-core.a` và `bamboo-core.h`
2. **Phần C++** (`src/`, `src/mint/`) — Engine fcitx5, build ra `libbamboo.so` và `libbamboomint.so`

> **Lưu ý quan trọng:** Mỗi khi sửa file `.go` hoặc `.cpp`, bạn **phải build lại** và **cài đặt lại** thư viện `.so` vào hệ thống. Fcitx5 không tự động reload thư viện động khi file `.so` thay đổi.

---

## 2. Chuẩn Bị Môi Trường Build

### 2.1. Gói hệ thống cần có (đã cài trên Linux Mint)

```bash
sudo apt update
sudo apt install -y \
    cmake extra-cmake-modules \
    libfcitx5core-dev libfcitx5config-dev libfcitx5utils-dev \
    fcitx5-modules-dev \
    golang-go \
    build-essential
```

### 2.2. Clone submodule lần đầu

Nếu mới clone repo hoặc chưa có thư mục `bamboo/bamboo-core/`:

```bash
cd /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo
git submodule update --init --recursive
```

> Nếu thiếu bước này, build sẽ lỗi vì không tìm thấy `go.mod` của `bamboo-core`.

## 3. Quy Trình Build Chi Tiết

### Bước 1: Dọn dẹp build cũ (khuyến nghị)

```bash
cd /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo
rm -rf build/
```

> Xóa build cũ để tránh trường hợp CMake cache còn lưu flag hoặc include path cũ.

### Bước 2: Tạo thư mục build và chạy CMake

```bash
mkdir -p build && cd build
cmake -DCMAKE_EXPORT_COMPILE_COMMANDS=ON ..
```

**Giải thích các flag:**
- `..` — Trỏ đến thư mục gốc chứa `CMakeLists.txt`
- `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON` — Sinh ra file `compile_commands.json` để Zed/VSCode hiểu code (không bắt buộc cho build nhưng giúp IDE không báo lỗi đỏ giả)

**Kết quả mong đợi:**
```
-- Found ECM: version 5.115.0
-- Found Fcitx5Core: version 5.1.7
-- Configuring done
-- Generating done
```

### Bước 3: Biên dịch

```bash
cd /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build
make -j4
```

- `-j4` — Chạy 4 thread song song (tùy chỉnh theo số CPU của máy, ví dụ `-j8`)

**Kết quả mong đợi (không có lỗi):**
```
[100%] Built target bamboo
[100%] Built target bamboomint
```

**Các file output được sinh ra:**

| File | Vị trí | Mô tả |
|------|--------|-------|
| `libbamboo.so` | `build/src/libbamboo.so` | Addon gốc bamboo |
| `libbamboomint.so` | `build/src/mint/libbamboomint.so` | Addon mới bamboo-mint |
| `bamboo.conf` | `build/src/bamboo.conf` | Cấu hình input method bamboo |
| `mint.conf` | `build/src/mint/mint.conf` | Cấu hình input method mint |
| `bamboo-addon.conf` | `build/src/bamboo-addon.conf` | Cấu hình addon bamboo |
| `mint-addon.conf` | `build/src/mint/mint-addon.conf` | Cấu hình addon bamboomint |
| `bamboo-core.a` | `build/bamboo/bamboo-core.a` | Thư viện Go biên dịch |
| `bamboo-core.h` | `build/bamboo/bamboo-core.h` | Header C từ Go generate |
| `compile_commands.json` | `build/compile_commands.json` | Dữ liệu cho clangd LSP |

## 4. Cài Đặt Sau Build

### 4.1. Cách 1: Cài đặt tự động bằng `make install` (vào `/usr/local/`)

```bash
cd /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build
sudo make install
```

**Nhược điểm:** Fcitx5 chạy trên hệ thống thường đọc từ `/usr/share/fcitx5/`, không đọc từ `/usr/local/share/fcitx5/`. Nên cách này chỉ cài thư viện `.so`, còn config cần copy thủ công thêm.

### 4.2. Cách 2: Cài đặt thủ công (khuyến nghị — chạy đúng ngay)

Sau khi `make -j4` thành công, chạy lệnh sau để copy file vào đúng vị trí hệ thống:

```bash
# 1. Thư viện .so (engine C++)
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/libbamboo.so \
        /usr/lib/x86_64-linux-gnu/fcitx5/

sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/mint/libbamboomint.so \
        /usr/lib/x86_64-linux-gnu/fcitx5/

# 2. File cấu hình addon (để fcitx5 biết có addon này)
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/bamboo-addon.conf \
        /usr/share/fcitx5/addon/bamboo.conf

sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/mint/mint-addon.conf \
        /usr/share/fcitx5/addon/bamboomint.conf

# 3. File cấu hình input method (để chọn từ tray)
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/bamboo.conf \
        /usr/share/fcitx5/inputmethod/bamboo.conf

sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build/src/mint/mint.conf \
        /usr/share/fcitx5/inputmethod/mint.conf

# 4. Từ điển tiếng Việt (dùng chung cho cả 2 addon)
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/data/vietnamese.cm.dict \
        /usr/share/fcitx5/bamboo/

# 5. Icon (nếu có thay đổi icon)
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/data/scalable/apps/fcitx_bamboo_mint.svg \
        /usr/share/icons/hicolor/scalable/apps/
sudo cp /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/data/scalable/apps/org.fcitx.Fcitx5.fcitx_bamboo_mint.svg \
        /usr/share/icons/hicolor/scalable/apps/
```

> **Tại sao phải copy thủ công?** Fcitx5 được cài từ gói `.deb` của distro, nó đọc addon từ `/usr/share/fcitx5/` và thư viện từ `/usr/lib/x86_64-linux-gnu/fcitx5/`. Còn `make install` mặc định cài vào `/usr/local/` mà fcitx5 không quét.

## 5. Reload và Test

### Bước 1: Restart fcitx5

Sau khi copy file `.so` mới, **bắt buộc** restart fcitx5 để nó load thư viện mới:

```bash
# Cách 1: Restart nhẹ nhàng (giữ lại profile, config)
fcitx5-remote -r

# Cách 2: Kill hẳn rồi chạy lại (nếu cách 1 không thấy thay đổi)
killall fcitx5
sleep 1
fcitx5 -d
```

### Bước 2: Kiểm tra các input method đang có

```bash
# Xem addon nào đang load
fcitx5-remote -m bamboo    # nên trả về: bamboo
fcitx5-remote -m mint      # nên trả về: mint
fcitx5-remote -m mozc      # nên trả về: mozc
fcitx5-remote -m pinyin    # nên trả về: pinyin
```

### Bước 3: Chuyển đổi giữa các bộ gõ

```bash
# Chuyển sang Bamboo gốc
fcitx5-remote -s bamboo

# Chuyển sang Bamboo Mint
fcitx5-remote -s mint

# Chuyển sang tiếng Nhật (Mozc)
fcitx5-remote -s mozc

# Chuyển sang tiếng Trung (Pinyin)
fcitx5-remote -s pinyin

# Xem đang dùng bộ gõ nào
fcitx5-remote -n
```

### Bước 4: Test gõ thử

Mở Text Editor (hoặc bất kỳ app nào hỗ trợ fcitx5), gõ thử tiếng Việt:

- Chọn `bamboo` → gõ `xin chao` → xuất `xin chào`
- Chọn `mint` → gõ `xin chao` → xuất `xin chào` (cùng engine nhưng chạy độc lập)
- Chọn `mozc` → gõ tiếng Nhật
- Chọn `pinyin` → gõ tiếng Trung

## 7. Troubleshooting — Các Lỗi Thường Gặp

### Lỗi 1: `bamboo-core.h: No such file or directory`

**Nguyên nhân:** Thiếu submodule `bamboo-core`.

**Sửa:**
```bash
git submodule update --init --recursive
```

### Lỗi 2: `Could not find a configuration file for package "Fcitx5Core"`

**Nguyên nhân:** Thiếu gói dev `libfcitx5core-dev`.

**Sửa:**
```bash
sudo apt install libfcitx5core-dev libfcitx5config-dev libfcitx5utils-dev fcitx5-modules-dev extra-cmake-modules
```

### Lỗi 3: `no type named 'string_view' in namespace 'std'` (lỗi trong Zed/IDE)

**Nguyên nhân:** `clangd` không biết compile flags (xem REQ-001, mục 3.10).

**Sửa:** Đã có file `.clangd` trong repo. Chỉ cần chạy:
```bash
cd /home/lmo1720/Fcitx-Bamboo-Mint/fcitx5-bamboo/build
cmake -DCMAKE_EXPORT_COMPILE_COMMANDS=ON ..
```

### Lỗi 4: `fcitx5-remote -s mint` không đổi được IM

**Nguyên nhân:** `mint` chưa được thêm vào `~/.config/fcitx5/profile`.

**Sửa:** Thêm `[Groups/0/Items/X]` với `Name=mint` vào file profile (xem REQ-001, mục 3.9).

### Lỗi 5: Build xong nhưng gõ không ra tiếng Việt

**Kiểm tra:**
1. File `.so` đã copy đúng chưa: `ls -la /usr/lib/x86_64-linux-gnu/fcitx5/libbamboomint.so`
2. Fcitx5 đã restart chưa: `fcitx5-remote -r`
3. Từ điển đã copy chưa: `ls -la /usr/share/fcitx5/bamboo/vietnamese.cm.dict`

### Lỗi 6: `fcitx5-remote` báo `0` (fcitx5 không chạy)

**Sửa:**
```bash
fcitx5 -d
```

## 10. Ghi Chú Thêm

- **Đừng sửa trực tiếp file trong `/usr/share/fcitx5/` hoặc `/usr/lib/...`** — luôn sửa trong source repo rồi build lại.
- **Nếu muốn cài đặt sạch sẽ hơn**, có thể build với prefix `/usr`:
  ```bash
  cmake -DCMAKE_INSTALL_PREFIX=/usr ..
  make -j4
  sudo make install
  ```
  Nhưng cần cẩn thận vì nó ghi đè lên file hệ thống.
- **Backup trước khi cài:** Nếu sợ hỏng, backup file `.so` gốc:
  ```bash
  sudo cp /usr/lib/x86_64-linux-gnu/fcitx5/libbamboo.so /usr/lib/x86_64-linux-gnu/fcitx5/libbamboo.so.bak
  ```
