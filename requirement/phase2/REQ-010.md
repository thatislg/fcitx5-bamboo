# REQ-010: Điều tra loại bỏ hoàn toàn engine `bamboo` gốc — chỉ giữ lại `bamboomint`

## Mục tiêu

Sau khi đã tạo thành công engine `bamboomint` (Bamboo Mint) chạy song song với `bamboo` gốc, bây giờ cần **xóa sạch** toàn bộ engine `bamboo` gốc khỏi source tree. Dự án chỉ còn duy nhất `bamboomint`.

> **Nguyên tắc:** Không xóa `bamboo/bamboo-core/` (thư viện Go) vì `bamboomint` vẫn phụ thuộc vào nó.

---

## Tổng quan ảnh hưởng

| Khu vực | Mức độ | Ghi chú |
|---------|--------|---------|
| Source C++ gốc | **Xóa hoàn toàn** | `src/bamboo.cpp`, `src/bamboo.h`, `src/bambooconfig.h` |
| Config addon gốc | **Xóa hoàn toàn** | `src/bamboo-addon.conf.in.in`, `src/bamboo.conf.in` |
| Build system (`src/CMakeLists.txt`) | **Sửa** | Bỏ target `bamboo`, chỉ giữ `add_subdirectory(mint)` |
| Build system (gốc `CMakeLists.txt`) | **Sửa** | Đổi tên project, đổi gettext domain |
| Dịch thuật (`po/`) | **Sửa** | Đổi domain từ `fcitx5-bamboo` → `fcitx5-bamboo-mint` |
| Metainfo XML | **Xóa hoặc đổi tên** | File `org.fcitx.Fcitx5.Addon.Bamboo.metainfo.xml.in` là của `bamboo` gốc |
| Dictionary path (`data/`) | **Quyết định** | Hiện tại `bamboomint.cpp` đọc dict từ `bamboo/vietnamese.cm.dict` |
| Zed diagnostics (`.clangd`) | **Sửa** | Cập nhật `FCITX_GETTEXT_DOMAIN` |

---

## 1. File cần XÓA

### 1.1. Engine C++ gốc

| File | Lý do xóa |
|------|-----------|
| `src/bamboo.cpp` | Engine gốc, đã có `src/mint/bamboomint.cpp` thay thế |
| `src/bamboo.h` | Header của engine gốc, không còn dùng |
| `src/bambooconfig.h` | Config struct của engine gốc, không còn dùng |

### 1.2. Config addon/inputmethod gốc

| File | Lý do xóa |
|------|-----------|
| `src/bamboo-addon.conf.in.in` | Đăng ký addon `bamboo` với fcitx5 |
| `src/bamboo.conf.in` | Đăng ký input method `bamboo` với fcitx5 |

> Sau khi xóa, trong thư mục `src/` chỉ còn:
> - `src/CMakeLists.txt`
> - `src/mint/` (engine mới)

---

## 2. File cần SỬA

### 2.1. `src/CMakeLists.txt`

**Hiện tại:**
```cmake
add_subdirectory(mint)

set( fcitx_bamboo_sources
    bamboo.cpp
)

add_fcitx5_addon(bamboo ${fcitx_bamboo_sources})
...
```

**Sau sửa:** Chỉ giữ lại dòng `add_subdirectory(mint)`. Toàn bộ block từ `set(fcitx_bamboo_sources` đến `install(... addon)` **bị xóa**.

**Kết quả:** CMake không còn build target `bamboo`, không còn sinh ra `libbamboo.so`.

---

### 2.2. `CMakeLists.txt` (gốc)

**Thay đổi 1 — Tên project:**
```cmake
# Cũ
project(fcitx5-bamboo VERSION 1.0.10)

# Mới
project(fcitx5-bamboo-mint VERSION 1.0.10)
```

**Thay đổi 2 — Gettext domain:**
```cmake
# Cũ
add_definitions(-DFCITX_GETTEXT_DOMAIN=\"fcitx5-bamboo\")

# Mới
add_definitions(-DFCITX_GETTEXT_DOMAIN=\"fcitx5-bamboo-mint\")
```

**Thay đổi 3 — Metainfo XML:**
- File `org.fcitx.Fcitx5.Addon.Bamboo.metainfo.xml.in` là của `bamboo` gốc (tên `Bamboo`, URL github gốc…).
- **Phương án A:** Xóa luôn block `fcitx5_translate_desktop_file(...)` và `install(... metainfo)` trong `CMakeLists.txt`, đồng thời xóa file `.in`.
- **Phương án B:** Tạo file metainfo mới cho `bamboomint` rồi sửa `CMakeLists.txt` trỏ sang file mới.

> **Đề xuất:** Phương án A (xóa) trước, vì metainfo không ảnh hưởng đến chức năng gõ. Có thể tạo lại sau nếu cần đóng gói.

---

### 2.3. `po/CMakeLists.txt`

**Hiện tại:**
```cmake
fcitx5_install_translation(fcitx5-bamboo)
```

**Sau sửa:**
```cmake
fcitx5_install_translation(fcitx5-bamboo-mint)
```

---

### 2.4. `Messages.sh`

**Hiện tại:**
```bash

```

**Sau sửa:**
```bash
gen_pot cxx:appdata:ui:desktop fcitx5-bamboo-mint po .
```

---

### 2.5. `.clangd`

**Hiện tại:**
```yaml
- -DFCITX_GETTEXT_DOMAIN="fcitx5-bamboo"
```

**Sau sửa:**
```yaml
- -DFCITX_GETTEXT_DOMAIN="fcitx5-bamboo-mint"
```

---

### 2.6. `data/CMakeLists.txt` — Đường dẫn từ điển

**Hiện tại:**
```cmake
install(FILES vietnamese.cm.dict DESTINATION "${FCITX_INSTALL_PKGDATADIR}/bamboo")
```

**Vấn đề:** Trong `src/mint/bamboomint.cpp` (dòng 243), engine đọc dict từ:
```cpp
"bamboo/vietnamese.cm.dict"
```

**Phân tích hai phương án:**

| Phương án | Thay đổi | Ưu điểm | Nhược điểm |
|-----------|----------|---------|-----------|
| **A — Giữ nguyên path** | Không sửa `data/CMakeLists.txt`, không sửa `bamboomint.cpp` | Đơn giản, không đụng code C++ | Vẫn còn tên `bamboo` trong path hệ thống |
| **B — Đổi path** | Đổi cả `data/CMakeLists.txt` (→ `bamboomint`) và `bamboomint.cpp` (→ `"bamboomint/vietnamese.cm.dict"`) | Sạch sẽ, không còn `bamboo` nào | Phải sửa code C++, cần test lại load dict |

> **Đề xuất:** Thực hiện **Phương án B** luôn trong cùng REQ này, vì đây là cơ hội tốt để "lau sạch" toàn bộ tên `bamboo` khỏi runtime.

## 4. Rủi ro & Kiểm thử

| Rủi ro | Mức độ | Phòng ngừa |
|--------|--------|------------|
| Build lỗi do thiếu file `bamboo.cpp` | Thấp | Đã xóa đúng target trong `src/CMakeLists.txt` |
| `bamboomint` không load được dict | Trung bình | Nếu đổi path, phải đổi đồng bộ cả `data/CMakeLists.txt` và `bamboomint.cpp` |
| Gettext không dịch được | Thấp | `BambooMintFactory::create()` đã gọi `registerDomain("fcitx5-bamboo-mint", ...)` đúng |
| CMake cảnh báo project name | Thấp | Đổi `project(...)` trong `CMakeLists.txt` gốc |

**Quy trình kiểm thử sau khi sửa:**
1. `rm -rf build && mkdir build && cd build && cmake .. && make -j4`
2. Xác nhận **chỉ** có `libbamboomint.so`, **không** có `libbamboo.so`
3. `sudo cp build/src/mint/libbamboomint.so /usr/lib/x86_64-linux-gnu/fcitx5/`
4. `sudo cp build/src/mint/mint-addon.conf /usr/share/fcitx5/addon/bamboomint.conf`
5. `sudo cp build/src/mint/mint.conf /usr/share/fcitx5/inputmethod/mint.conf`
6. Nếu đổi path dict: `sudo mkdir -p /usr/share/fcitx5/bamboomint && sudo cp data/vietnamese.cm.dict /usr/share/fcitx5/bamboomint/`
7. `fcitx5-remote -r`
8. Mở Zed / Text Editor, chuyển sang `Bamboo Mint`, gõ thử tiếng Việt.
