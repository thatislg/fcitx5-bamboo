# REQ-027: Chú thích các file `*_test.go` — Test suite của bamboo-core

## 1. Mục đích

Ba file test trong `bamboo/bamboo-core/` kiểm tra toàn bộ chức năng của engine tiếng Việt:

| File | Số lượng test | Mục đích chính |
|------|---------------|----------------|
| `bamboo_test.go` | ~40 test cases + 1 benchmark | Test engine chính: gõ phím, xóa, chuyển đổi, chính tả |
| `rules_parser_test.go` | ~4 test cases | Test parse rule từ chuỗi định nghĩa kiểu gõ |
| `utils_test.go` | ~4 test cases | Test hàm tiện ích: nguyên âm, dấu thanh, dấu phụ |

## 2. `bamboo_test.go` — Test engine chính

### 2.1. newStdEngine() — Helper khởi tạo engine test

```go
func newStdEngine() IEngine {
    var im = ParseInputMethod(InputMethodDefinitions, "Telex 2")
    return NewEngine(im, EstdFlags)
}
```

- **Logic:** Parse kiểu gõ "Telex 2" từ định nghĩa mặc định, tạo engine với cờ chuẩn (`EstdFlags = EfreeToneMarking | EstdToneStyle | EautoCorrectEnabled`).
- **Ý nghĩa:** Tất cả test đều dùng engine này để đảm bảo môi trường nhất quán.

## 3. `rules_parser_test.go` — Test parse rule

### 3.1. `TestParseToneRules`

- **Kiểm tra:** Parse rule dấu thanh từ macro.
- **Test cases:**
  - `'z'` + `"XoaDauThanh"` → 1 rule `ToneTransformation` với `ToneNone`
  - `'x'` + `"DauNga"` → 1 rule `ToneTransformation` với `ToneTilde`

### 3.2. `TestParseTonelessRules`

- **Kiểm tra:** Parse rule dấu phụ (mark) và appending từ macro.
- **Test cases:**
  - `'d'` + `"D_Đ"` → 2 rules: `MarkDash` trên `d` + `Appending` `Đ`
  - `'{'` + `"_Ư"` → 1 rule `Appending` `Ư`
  - `'w'` + `"UOA_ƯƠĂ"` → 33 rules (parse đầy đủ các mark từ macro)
  - `'w'` + `"UOA_ƯƠĂ__Ư"` → 34 rules (thêm appending `ư`)

### 3.3. `TestAppendRule`

- **Kiểm tra:** Parse rule có `AppendedRules` (rule đi kèm).
- **Test cases:**
  - `'['` + `"__ươ"` → 1 rule với `AppendedRules[0]` là `Appending` `ơ`
  - `'{'` + `"__ƯƠ"` → 1 rule với `AppendedRules[0]` là `Appending` `Ơ`

### 3.4. `TestParseRulesWithIm`

- **Trạng thái:** Trống (chưa implement).

## 4. `utils_test.go` — Test hàm tiện ích

### 4.1. `TestIsVowel`

- **Kiểm tra:** Hàm `IsVowel()` nhận diện đúng nguyên âm tiếng Việt.
- **Logic:**
  - `'a'`, `'á'` → `true`
  - `'b'` → `false`
  - Duyệt toàn bộ 84 nguyên âm (bao gồm cả có dấu) → tất cả đều `true`
- **Chuỗi test:** `"aàáảãạăằắẳẵặâầấẩẫậeèéẻẽẹêềếểễệiìíỉĩịoòóỏõọôồốổỗộơờớởỡợuùúủũụưừứửữựyỳýỷỹỵ"`

- **Test cases:**
  | Ký tự | Dấu thanh |
  |-------|-----------|
  | `e` | `ToneNone` |
  | `è` | `ToneGrave` |
  | `é` | `ToneAcute` |

## 6. Đề xuất chú thích

Thêm block header tiếng Việt ở đầu mỗi file test, sau header bản quyền. Chú thích theo pattern:

```go
// TestXYZ kiểm tra ...
//
// Input: ...
// Expected: ...
// Ý nghĩa: ...
func TestXYZ(t *testing.T) { ... }
```
